# Sapphire Full-Stack Internship Project

This repository is structured according to the official intern guidelines, featuring a `/client` and `/server` architecture, along with a complete tech stack implementation[cite: 1].

---

## 📂 Folder Structure
* `/client` — Frontend application built for UI, SPA routing, and API consumption[cite: 1].
* `/server` — Backend application built for REST APIs, authentication, and security middleware[cite: 1].

---

## ⚙️ Tech Stack

| Layer | Technologies | Purpose |
| :--- | :--- | :--- |
| **Frontend** | React 18+, Vite, Tailwind CSS, React Router v6, Axios | UI, SPA routing, API consumption[cite: 1] |
| **Backend** | Node.js LTS, Express.js, JWT, bcrypt, dotenv, cors, helmet | REST API, auth, security middleware[cite: 1] |
| **Database** | PostgreSQL + Sequelize ORM | Relational data modelling and querying[cite: 1] |
| **Dev Tools** | VS Code, Postman, Git & GitHub, Nodemon, ESLint + Prettier | Version control, quality, testing[cite: 1] |
